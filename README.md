# expense-tracker:
A CLI project that allows you to track your expenses by adding categories and expenses to each category. 

# features:
Expenses can be added to specific categories so there is an add category feature and add expense feature. 
Mistakes can be made so there is an option to delete categories and expenses.
In order to review your personal expenses, there is an option to view categories, individual expenses and total expenses. 

# how to run:
1. Clone the repository
2. Ensure you have Python 3 installed (check by entering 'python --version' or 'python3 --version' onto your computer's command prompt and run it)
3. Run 'python expense_tracker.py' or 'python3 expense_tracker.py' in your command prompt depending on what worked in step 2.
